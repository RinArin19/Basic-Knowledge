# Security Hygiene for Everyone: Passwords, MFA, Updates, and Backups

**Segment:** Everyday security. **Audience:** all staff, and a handout for security awareness training. **Goal:** build four habits that close many of the gaps everyday attacks rely on.

Unique passwords, MFA, updates, and tested backups are small habits, and together they close many of the gaps everyday attacks rely on.

## Four habits

| Habit | How to do it | Why it helps |
|---|---|---|
| Unique passwords | Use a password manager and a long, random password for every account | One breach does not unlock your other accounts |
| MFA | Turn it on everywhere, and prefer an authenticator app or hardware key over SMS | A stolen password alone is not enough |
| Updates | Enable automatic updates for the operating system, browser, and apps | Fixes known flaws that attackers actively use |
| Backups | Keep copies on a separate device or service and test a restore | You can recover from ransomware, loss, or failure |

## Spot a scam in ten seconds

- Is it urgent or threatening?
- Does it ask for a password, a code, or a payment?
- Is the sender or link slightly off?
- Can you check it through a separate channel?

If any answer is yes, stop and report it.

## If you think you were tricked

- Report it to IT or security right away. Early reports limit the damage, and nobody is blamed for reporting.
- Change the password from a device you trust and sign out of other sessions.
- Tell the security team exactly what you clicked or entered.

## Common mistakes

- Reusing a password with small changes.
- Approving an MFA prompt you did not start.
- Putting off updates for weeks.
